# Список задач

Минималистичный список задач в редакционной стилистике Inset. Задачи можно добавлять, редактировать, отмечать выполненными и удалять.

- Календарь в поле новой задачи позволяет указать необязательный срок. Для существующих задач срок меняется в редакторе.
- Сортировка по времени добавления и ближайшему сроку. В режиме «По ближайшему сроку» задачи без даты идут в конце.
- Фильтр показывает все, активные или выполненные задачи.
- Счётчик показывает, сколько задач выполнено из общего числа.
- Кнопка «Отменить» возвращает последнюю удалённую задачу в течение 6 секунд. Отсчёт приостанавливается при наведении на уведомление или переводе фокуса на его кнопки.

Задачи, сроки, отметки и выбранная сортировка сохраняются в браузере после обновления страницы.

## Запуск

Из корня проекта запустите локальный сервер:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте [localhost:8000](http://127.0.0.1:8000). Сайт написан на HTML, CSS и JavaScript. Для запуска достаточно статического сервера. Данные хранятся в `localStorage` для текущего браузера и адреса сайта.
